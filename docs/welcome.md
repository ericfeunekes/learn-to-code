AI can write the code. Learn to understand the relevant concepts, make choices,
and judge the result as you build an app you want to use.

## Start with something useful

Choose a small, low-stakes project. The [course overview](course/OVERVIEW.md)
sets out the outcomes and helps you define a useful first version.

## Learn, apply, revisit

Follow the [seven-module learning path](course/CURRICULUM.md), from testing and
failure recovery to data, program structure and concurrency. Each module names
what you should be able to explain, decide and direct AI to do.

Work at your own pace. Follow questions that interest you and return to earlier
ideas as your project gives you new reasons to use them.

## Bring your AI

The [teaching guide](course/AI-TEACHER.md) and
[project practice](course/PRACTICE.md) connect explanation, questions and real
work. The [AI reading guide](for-ai.md) provides the same course in plain
Markdown.
