# Module 6 — Structuring a program

**Being built**

This module will explore how a program’s responsibilities and dependencies fit
together when understanding or changing an app.

Intended coverage:

- Following an action through components, data, and external calls.
- Grouping responsibilities, managing dependencies, and locating shared rules.
- Interfaces, dependency direction, and supplying dependencies from outside a
  component.
- Planning a focused change across components while preserving the behavior
  callers rely on.

This is a broad outline for future development with the course author. Detailed
objectives and examples still need to be developed together and reviewed by the
course author before this module is ready to teach.
