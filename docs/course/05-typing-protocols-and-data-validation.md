# Module 5 — Typing, protocols, and data validation

**Being built**

This module will explore how code describes data and promises, and how an app
checks incoming values.

Intended coverage:

- What types communicate and what static and runtime checks can establish.
- Representing valid values, missing data, and different states.
- Protocols and interfaces as promises between callers and implementations.
- Validating the shape and meaning of external data before using it.
