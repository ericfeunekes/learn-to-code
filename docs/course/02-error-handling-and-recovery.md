# Module 2 — Error handling and recovery

**Being built**

This module will explore how to understand failures and decide what an app
should do next.

Intended coverage:

- Diagnosing failures from errors, logs, and observed behavior.
- Choosing how to handle different failures, including when retrying is useful.
- Giving users useful feedback while keeping diagnostic information appropriate.
- Understanding interrupted operations, uncertain outcomes, and recovery
  choices.

This is a broad outline for future development with the course author. Detailed
objectives and examples still need to be developed together and reviewed by the
course author before this module is ready to teach.
