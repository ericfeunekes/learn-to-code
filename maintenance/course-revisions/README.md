whole course, use independent learner project repositories, and develop Module 2
as a detailed draft pending course-author review. They are proposed revisions to
the canonical general sources, not learner records. The source files in Drive
remain unchanged.

generated copy. The Module 2 candidate is preserved from its separately reviewed
