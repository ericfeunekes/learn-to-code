# General course revisions

These seven authoring files maintain the shared overview, setup, curriculum,
teaching/practice guidance, GitHub foundation and building Module 2. The
original canonical source files remain unchanged.

`../course-refinements.json` registers each revision with its original source
hash. Refresh through the [publication workflow](../publication.md); edit these
inputs rather than their generated `docs/course/` snapshots. If a canonical
source changes, reconcile it and its registered revision together instead of
weakening the hash guard.

- [Overview](OVERVIEW.md): both learning paths and how to begin.
- [Setup](SETUP.md): independent projects, course references and enterprise use.
- [Course map](CURRICULUM.md): modules and further directions.
- [Teacher guide](AI-TEACHER.md): adaptive learning and evidence review.
- [Practice](PRACTICE.md): application and accessible evidence return.
- [GitHub foundation](00-project-and-git.md): shared repository concepts.
- [Error handling and recovery](02-error-handling-and-recovery.md): building
  Module 2.

The understanding track is authored directly in `docs/understand-code/`. Its
examples and downloadable fixtures use fictional data. Individual module pages
carry their content-status labels. Earlier companion URLs point into that track.
There is one maintained authoring source for each page.

Relative links here target the generated `docs/course/` location. Navigate the
rendered pages for learning; this directory supplies the importer.
