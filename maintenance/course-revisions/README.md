whole course and use independent learner project repositories. They are proposed
revisions to the canonical general sources, not learner records. The source
files in Drive remain unchanged.

`../course-refinements.json` registers each file with the original source hash.
Use the
[publication workflow](../publication.md#course-revisions-for-separate-learner-repositories)
to refresh generated pages and reconcile future canonical updates. Review this
authored text together with the `docs/course/` diff; edit here, not in the
generated copy. These files contain no detailed Module 2 changes.

- [Overview](OVERVIEW.md): destination, practical core topics, and project flow.
- [Setup](SETUP.md): an independent project repository and next choices.
- [Course map](CURRICULUM.md): the learner journey and further directions.
- [Teacher guide](AI-TEACHER.md): independent application and accessible

- [Git/GitHub draft](00-project-and-git.md): project-repository context.

Relative links in the authoring files target their generated `docs/course/`
location. They become valid reading links after import; use those generated
pages to navigate the course. This directory is an authoring input, not another
public site or a standalone reference checkout.
